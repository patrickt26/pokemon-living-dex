# Assets

Sprites Pokémon são referenciados pelo catálogo gerado e carregados do repositório público de sprites da PokéAPI. Logos de jogos ficam em `public/game-logos` para evitar dependência de rede durante a navegação.

Pokémon e os nomes/logos dos jogos são marcas de Nintendo, Creatures Inc. e GAME FREAK. Os assets são usados somente para identificação dentro deste projeto de coleção, sem reivindicação de propriedade. Antes de uma publicação comercial, revise permissões, fontes e requisitos de atribuição de cada imagem.
